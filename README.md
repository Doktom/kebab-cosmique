# Kebab Cosmique

Jeu navigateur de gestion / crafting / automatisation roguelite : tiens un stand de kebab sur un astéroïde et survis au loyer du proprio galactique.

Jouer : https://doktom.github.io/kebab-cosmique/

Un seul fichier (`index.html`), aucune dépendance. La progression est sauvegardée dans le navigateur (localStorage).
